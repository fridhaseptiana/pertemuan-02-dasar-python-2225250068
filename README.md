## Tujuan Repositori

Repositori ini dibuat untuk memenuhi tugas praktik Kuis 1 pada mata kuliah Algoritma dan Pemrograman. Repositori berisi beberapa latihan dasar Python dan tugas utama berupa program Kalkulator Koordinat Dua Titik.

Program Kalkulator Koordinat digunakan untuk menerima koordinat dua titik, menghitung perubahan koordinat, jarak Euclidean antara dua titik, serta titik tengah dari kedua titik.

## Daftar Berkas

| Berkas | Fungsi |
|---|---|
| `latihan/03_konversi_suhu.py` | Mengonversikan suhu dari Celsius ke Fahrenheit dan Kelvin. |
| `latihan/04_nilai_akhir.py` | Menghitung nilai akhir berdasarkan nilai tugas, UTS, dan UAS dengan bobot 20%, 30%, dan 50%. |
| `tugas/kalkulator_koordinat.py` | Menghitung perubahan koordinat, jarak Euclidean, dan titik tengah dari dua titik. |
| `README.md` | Berisi informasi mengenai repositori, cara menjalankan program, hasil pengujian, dan refleksi. |
